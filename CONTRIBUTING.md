# Contribuir

Issues e pull requests são bem-vindos. Descreva o problema, os passos para o reproduzir e o comportamento esperado. Não inclua dados pessoais, credenciais ou rascunhos reais.

Para alterações maiores, abra primeiro uma issue. Mantenha as alterações focadas e execute as verificações indicadas no README antes de abrir um pull request. Inclua testes quando alterar comportamentos.

As contribuições são disponibilizadas sob Apache-2.0. Não apresente integrações como oficiais sem autorização do operador. Os pedidos oficiais continuam a ser concluídos pela pessoa no portal respetivo.
